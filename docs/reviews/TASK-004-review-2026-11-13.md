## 3. Concurrency / side effects

- `requestExit()` đảm bảo `exit()` chỉ gọi một lần kể cả khi signal thứ hai hoặc timeout cứng chạy trước.
- Cleanup chạy ngược thứ tự đăng ký, mỗi handler có timeout 20s và lỗi của handler này không chặn handler khác.
- `uncaughtException`/`unhandledRejection` trước đây làm process chết không dọn dẹp; nay đi qua cùng một đường shutdown.

## 4. Missing tests

- Chưa có integration test gửi SIGINT/SIGTERM thật cho process có Playwright (cần browser + Telegram session). Đã thay bằng test với `EventEmitter` giả lập `processRef`, phủ: signal đầu → shutdown, signal thứ hai → exit ngay, uncaughtException → cleanup.
- Heartbeat interval 30s chưa được test theo thời gian thực (đã test ghi file + `updateHeartbeat`).
