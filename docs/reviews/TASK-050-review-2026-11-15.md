## 3. Chất lượng thiết kế

- Tách `readLockFile()` khỏi state reader: lock và state có ngữ nghĩa lỗi khác nhau, không dùng chung fallback.
- `isLockRecord()` kiểm tra đúng trường tối thiểu (`token`, `pid`, `leaseUntil`) — chặn cả JSON hợp lệ nhưng shape sai.
- Lỗi có `code`, `lockPath`, `quarantinePath`, message hướng dẫn → vận hành được.
- Heartbeat/release chọn "không làm gì" thay vì throw: worker đang chạy vẫn nhận tín hiệu dừng, không crash loop.

## 4. Điểm cần lưu ý

1. File lock gốc được giữ nguyên nên agent tiếp tục chặn ở mỗi lần khởi động cho tới khi con người xử lý — đúng fail-closed, đã ghi README.
2. `agentIsRunning()` coi lock hỏng là đang chạy nhưng không tự quarantine; CLI chỉ đọc. Quarantine do registry thực hiện khi agent khởi động — chấp nhận được.
3. Nếu ổ đĩa đầy, copy quarantine lỗi nhưng vẫn ném `AGENT_LOCK_CORRUPT` (không mất tính fail-closed).
